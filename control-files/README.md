# Lampy cargo-install control files — DRAFT 2026-09-19

Machine-readable manifests for the extension builds in the Lampy stack.
pgrx is the Rust framework that builds Postgres extensions; pgai (AI access
to the vectorized database) and pgvectorscale are pgrx-built extensions, and
TimescaleDB ships in the same stack as a C/pgxs extension. Components covered:
pgrx, timescaledb, timescaletools, pgvectorscale, pgai.

## Source

Derived from Kit's 2025-02-23 "Docker progress" Facebook post (Dockerfile
sketch), which generated per-component `toml/<name>.toml` files plus
`conf/pgrx.conf` / `conf/pgai.conf` (contents never specified in the sketch).

## Format decisions (draft)

- The sketch's TOML was not valid TOML (bare string lists, `- ` items, a
  stray `]`). These drafts are **valid TOML** preserving the sketch's
  semantics: `[workspace]` member list + `[dependencies]` lists.
- `json/` mirrors the same data as canonical machine-readable JSON.
- `yaml/` mirrors the same data as YAML (added 2026-09-19 at Kit's direction).
- **Canonical rule: `toml/` is the source of truth.** The `json/` and `yaml/`
  mirrors are generated by parsing the TOML (round-trip verified: reparsing
  the mirror must equal the TOML parse). Never edit a mirror by hand;
  regenerate it from the TOML.
- `conf/` holds the two `.conf` files: full environmental configuration for
  the pgrx build side (`pgrx.conf`) and the pgai/vectorizer side (`pgai.conf`),
  transcribed from the sketch's ENV block and corrected per `env.sh`.

## Bugs fixed vs the sketch

1. The sketch's final line `echo 'expose $ROOT/"pgrx".toml' > $ROOT/toml/pgrx.toml`
   used `>` and would have **overwritten the entire file** it just built.
2. `/n` used instead of `\n` in the `.env` generation (different file, noted).
3. `gnupgn` → `gnupg`, `nopenssl-dev` → `openssl-dev` (presumed typos).

## Version updates vs the sketch

- PostgreSQL **16** (sketch: 17) — matches the production
  `timescale/timescaledb-ha:pg16` decision.
- cargo-pgrx **0.19.2** (sketch: 0.12.8) — matches the reference host install.
- Web server **httpd** (already in the sketch's member list; replaces nginx
  per Kit's 2026-09-19 decision).

## Platform notes

- `PGRX_BUILD_FLAGS=TRUE` is Kit's tested Windows setting (in the sketch).
  cargo-pgrx 0.19.2 on the reference Linux host treats `TRUE` as a rustc
  filename and fails — so the drafts carry it as a Windows-only entry.
  Retest only against the exact Windows/WSL2 toolchain.
- `PGRX_IGNORE_RUST_VERSIONS=1` and `CARGO_TARGET_DIR` under the workspace
  come from `~/workspace/forum-stack/env.sh` (reference host).
